# Divine Sovereignty Frontend (React + TypeScript + Tailwind)

Responsive personal-brand landing page with offerings, donations, mailing list capture, enterprise contact, and an optional 528Hz ambient audio toggle.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Build

```bash
npm run build
```

## Key Features

- Responsive landing page with hero, philosophy, offerings, founder vision, and legal footer
- Stripe-powered one-time purchase and donation entry points
- Mailing list capture and enterprise inquiry form integration
- Optional 528Hz ambient audio toggle
- Mobile-first styling with Tailwind and subtle scroll fade-ins

## Environment

- `VITE_API_BASE_URL` — backend base URL (default `http://localhost:8000`)
